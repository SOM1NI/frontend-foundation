REST API

Endpoints for todos, categories, comments, users, and roles.

The local server exposes JSON routes under /api. Run it with npm.cmd start, then use bearer tokens from the login route for protected operations.

POST

/api/auth/register

Create a user account with name, email, and password. New accounts receive the member role.

POST

/api/auth/login

Exchange credentials for a signed bearer token and the current user profile.

GET

/api/tasks

Return visible tasks with owner, status, category, priority, due date, and comments.

POST

/api/tasks

Create a task. Required body: title. Optional: details, category, priority, dueDate.

PATCH

/api/tasks/:id

Update title, details, category, priority, due date, assignee, or completed state.

DELETE

/api/tasks/:id

Delete a task owned by the signed-in user or by any user when the requester is an admin.

GET

/api/categories

Return category names and colors used for task grouping in the dashboard.

POST

/api/tasks/:id/comments

Attach a timestamped note to a task so status updates stay connected to the work item.

GET

/api/admin/users

Admin-only route for account audit views and role management surfaces.

Example request

Create a task from any JavaScript client.

const response = await fetch("/api/tasks", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    Authorization: `Bearer ${token}`
  },
  body: JSON.stringify({
    title: "Review sprint goals",
    category: "Planning",
    priority: "High",
    dueDate: "2026-10-25"
  })
});

const task = await response.json();

Task schema

Designed for practical task-management flows.

  • id, title, details
  • category, priority, dueDate
  • completed, ownerId, assignee
  • comments, createdAt, updatedAt
