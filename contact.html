Local Setup

Run the complete site and API.

  1. Open a terminal in frontend-foundation.
  2. Run npm.cmd start.
  3. Visit http://localhost:3000.
  4. Log in with admin@taskforge.dev and admin123.

Production checklist

  • Set a strong JWT_SECRET.
  • Move persistence to MongoDB with Mongoose models.
  • Serve behind HTTPS.
  • Add audit logs for role changes.
